# 专业流程

读取故事→页格规划→人物与图像职责→关联实际图像→气泡排版→阅读检查→区域意见→局部换图→固定交付。

漫画工程作为当前作品的专业成果，不新增宿主作品类型。分格和气泡使用规范化坐标，页面保存明确尺寸及左右阅读方向。示意格不冒充完成画面；图像只消费当前作品固定PNG/JPEG来源。HTML内嵌图像离线可读，未配图和越界单独检查，导出不表示作者认可。

- 左右阅读顺序与同页唯一序号。
- 越界、孤立气泡和错误图像来源拒绝。
- 未知图像保持占位，实际素材与示意分开。
- 中文长对白、窄窗、浅暗与键盘阅读。
- 替换单格后旧图像意见保持固定旧版，离线导出无远端依赖。

旧来源与专业依据保持固定，更新以影响分析开始，不批量覆盖旧记录。

大工程写入和原键回读可传detail=summary，返回固定对象元数据及content_read；按固定修订export_project的8192字节JSON分块恢复完整工程。get_source按UTF-8偏移分块，complete只表示返回范围，不表示已理解全文。GUI可在受管桌面传输使用full；不能为机器入口切换all-tools或依赖窗口。
